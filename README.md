# SuperAhorro 🇪🇸

MVP de un comparador de precios de supermercados en España.

## Estado actual

Base inicial del proyecto. Cualquier producto o precio de demostración debe estar claramente marcado como ficticio; no se presentarán datos inventados como precios reales.

## Objetivo

- Buscar productos y comparar precios entre supermercados.
- Crear una cesta y comparar el coste total.
- Incorporar fuentes de precios autorizadas, con fecha de actualización y cobertura geográfica.

## Arquitectura prevista

- Frontend: Next.js + TypeScript
- API: FastAPI
- Base de datos: PostgreSQL
- Desarrollo y despliegue: Docker Compose

## Próximos pasos

2. Añadir base de datos y datos de demostración claramente identificados.
